# 全参考模式 - 改写输出格式指南（中文版）

本指南说明在全参考模式下如何组织和编写改写输出。

所有六个改写部分用英文书写。仅在 `<d>` 标签内的对话/歌词和场景中可见的文字中保留原始语言。

**描述细节要求**：让 `detailed_description` 尽可能详细和明确。每个镜头都应清楚建立当前构图、主体外观和位置、环境与光线、动作与状态变化、摄像机运动、当前声音，以及参考内容实际出现或生效的位置。避免将描述简化为情节摘要或参考关系列表。

> 镜头、摄像机运动、说话人、对话和普通声音的基本格式与 视频提示词写作指南（T2VA / I2VA / FL2VA / L2VA）共享。本指南聚焦于全参考模式特有的参考标签、分析章节和格式差异。

## 1. 整体结构

完整的改写输出包含六个部分，按以下顺序排列：

| 部分 | 用途 |
| --- | --- |
| `subject_definitions` | 定义参考内容及其参考标签 |
| `summary` | 总结任务类型、目标视频和主要参考关系 |
| `retention_analysis` | 描述参考内容如何被保留、转移或复用 |
| `detailed_description` | 按播放顺序描述视觉、动作、镜头、声音和对话 |
| `overall_soundscape` | 总结环境和物理声音 |
| `non_diegetic_music` | 描述只有观众能听到的背景音乐 |

## 2. 参考标签与定义（subject_definitions）

全参考改写使用四种标签来标识参考内容的来源和角色：

| 标签 | 含义 |
| --- | --- |
| `<Subject N>` | 从参考资产中抽象出的可视内容，可在目标视频中复用或修改 |
| `<Picture N>` | 用作具体目标帧或镜头规划锚点的参考图像 |
| `<Video N>` | 提供编辑源、延续起点或全视频时间结构的参考视频 |
| `<Audio N>` | 被复制或参考的音频信号 |

> 一旦某个参考标签分配给一段内容，它在 `subject_definitions`、`summary`、`retention_analysis`、`detailed_description` 和音频部分中保持相同的含义。

`subject_definitions` 定义每段需要在后续单独跟踪的参考内容，如人物、环境、源视频的结构或音频轨道。每项独占一行，说明其标签的含义、参考角色以及需要遵循的主要特征；需要明确来源时请指明对应的源资产。如果 `<Picture N>` 或 `<Video N>` 仅用于标识另一参考项的来源，自身不会在后续被单独分析或使用，则在对应项的定义中引用它，无需新增单独行。`retention_analysis` 记录各参考项出现的位置以及是全部保留、部分保留、转移还是复用。

### 2.1 `<Subject N>`

`<Subject N>` 用于可复用的可视内容，包括：
- 人物、动物或物体
- 场景、背景或环境
- 服装、道具、界面或视觉特效
- 风格、动作、表情或姿态

它代表将在目标视频中实际使用的内容单元，而非源文件本身。一个主体可由多个参考资产定义，一个参考资产也可提供多个主体。

```text
<Subject 1> 是 <Picture 1> 中的年轻女性，拥有深色长发、蓝色开衫和一条细银项链。
```

当同一主体来自多个资产时，合并来源并说明各资产提供的内容：

```text
<Subject 1> 是其外貌来自 <Picture 1>、走路动作来自 <Video 1> 的女性。
```

### 2.2 `<Picture N>`

当参考图像本身作为镜头的首帧、关键帧、末帧、编辑关键帧或构图锚点时，使用独立的 `<Picture N>`：

```text
<Picture 2> 是 [Shot 1] 的首帧，展示一位女性坐在咖啡馆窗边。
```

如果图像仅用于定义角色、场景、服装或风格，不要创建独立的 Picture 条目，而是在对应的 `<Subject N>` 定义中引用该图像来源。

当图像用作分镜或镜头规划参考时，说明它映射到哪些镜头及提供哪些规划信息：

```text
<Picture 3> 是 [Shot 1] 和 [Shot 2] 的分镜参考，定义了它们的视角、主体位置和镜头顺序。
```

### 2.3 `<Video N>`

`<Video N>` 保留用于全视频级别的关系：
- 编辑原始视频
- 从原始视频结尾延续
- 参考原始视频的摄像机运动、剪切、节奏或时间结构

```text
<Video 1> 是目标视频编辑的源视频。
```

如果参考视频中的人物、物体、场景、动作或特效被复用为可视内容，仍应归入 `<Subject N>`。`<Video N>` 标识资产或结构来源，不替代主体标签。

### 2.4 `<Audio N>`

`<Audio N>` 代表独立的音频资产或参考视频中启用的同步音频轨道。常见用途包括：
- 复制全部或部分音频信号
- 参考背景音乐风格
- 参考说话人的音色和表达方式
- 使用原始音频中的对话、歌词或音效
- 参考节拍、节奏或音频连续性

当 `<Audio N>` 明确对应目标说话人时，在定义中复用该说话人的全局 ID：如果说话人对应用已定义的 subject，写 `<Subject N> (Sx)`；否则用稳定的声音描述后跟 `(Sx)`。ID 来自目标视频的全局说话人顺序，不在音频定义中独立分配或重新编号。参见第 5.4 节说话人编号规则：

```text
<Audio 1> 是 <Subject 1> (S1) 的音色参考。
```

当一个音频资产承担多种角色时，在一个自然句中描述这些角色，不要额外划分子章节。

### 2.5 来自同一参考视频的画面与音频轨道

`<Video N>` 和 `<Audio N>` 各自独立编号。每个索引仅表示该标签在自身类别中的顺序，不编码两类之间的配对关系。同一参考视频可能对应 `<Video 1>` 和 `<Audio 2>`；不同索引并不妨碍它们来自同一源资产。

普通参考视频不会仅因文件包含声音就创建 `<Audio N>`。

`<Audio N>` 定义主要陈述音频的角色，无需指定其来自哪个 `<Video N>`。仅当需要消除来源歧义时才说明共享源，例如：

```text
<Video 1> 是目标视频编辑的源视频。
<Audio 2> 是 <Video 1> 的同步音频轨道，在目标视频中被复用。
```

## 3. summary（摘要）

用一个简短的英文段落总结目标视频及其参考关系。以方括号括起的任务类型前缀开头：

```text
[reference generation] ...
[video editing + reference generation + audio reuse] ...
```

按各参考资产在目标视频中的实际角色选择任务类型：

| 任务类型 | 使用场景 |
| --- | --- |
| `keyframe completion` | 图像作为目标视频的首帧、关键帧、末帧、编辑关键帧或其他具体帧锚点 |
| `reference generation` | 图像/视频/音频为角色、场景、风格、动作、运镜、分镜等提供生成指导，不充当具体帧或被编辑/延续的源视频 |
| `video editing` | 直接修改现有源视频；编辑图像或在静态关键帧之间生成不属于此类型 |
| `video continuation` | 新内容延续、扩展、接续或过渡自现有源视频 |
| `audio reuse` | 同一音频信号被全部或部分复用 |
| `audio reference` | 未直接复制音频信号，仅参考其音乐风格、音色、对话/歌词内容、音效质感、节拍或连续性 |

当任务满足多种关系时，用 ` + ` 组合类型且不重复。例如，从源视频延续同时用图像作末帧写为 `[video continuation + keyframe completion]`。编辑源视频同时保留原始音频可写为 `[video editing + audio reuse]`。

视频或音频的存在不会自动产生对应任务类型。如果参考视频仅提供运镜、剪切或节奏，通常属于 `reference generation`。仅在直接编辑或延续该视频时使用 `video editing` 或 `video continuation`。

编辑源视频时，如果其原始音频仍然可闻，则同时使用 `audio reuse`。延续源视频但未直接复制音频信号时，如果新音频仅延续原始轨道的可闻特征，则使用 `audio reference`。

摘要使用已定义的参考标签来描述主要主体、镜头流程和参考资产的角色。不要在此引入新的参考标签。

对于视频编辑任务，在任务类型前缀后以以下格式开头：

```text
目标视频是 <Video 1> 的编辑版本。
```

## 4. retention_analysis（保留分析）

本部分描述每段参考内容在目标视频中如何被保留、转移、复制或参考。每个参考标签占一行，保持 `subject_definitions` 中建立的含义。

### 4.1 可视内容

`<Subject N>`、`<Picture N>` 和 `<Video N>` 使用以下关系标记（固定在输出格式中的英文值）：

| 关系标记 | 含义 |
| --- | --- |
| `fully_preserved` | 参考内容的定义角色被完全保留 |
| `partially_preserved` | 参考内容仍被使用，但部分定义特征发生变化或仅部分保留 |
| `attribute_transfer` | 参考特征转移到不同的可识别目标主体 |
| `weak_reference` | 仅在风格、类别、构图或氛围方面保留广泛相似性 |

Subject 条目：
```text
<Subject 1>（出现在 [Shot 1]、[Shot 3]）：fully_preserved - ...
```

Picture 条目：
```text
<Picture 2>（[Shot 1] 首帧）：fully_preserved - ...
```

Video 结构条目：
```text
<Video 1>（剪切和节奏结构）：weak_reference - ...
```

### 4.2 音频

`<Audio N>` 使用以下关系标记：

| 关系标记 | 含义 |
| --- | --- |
| `fully_copy` | 完整的源音频作为目标视频的完整最终音频轨道 |
| `partially_copy` | 仅部分时间线或选择的音频层被复制，或复制后添加、删除、替换了其他声音 |
| `reference` | 未直接复制信号；仅参考音色、节奏、音乐风格、对话内容或声音质感 |
| `weak_reference` | 仅在类别或氛围方面保留广泛相似性 |

```text
<Audio 1>：fully_copy - <Audio 1> 被 1:1 复用为目标视频的完整最终音频轨道。
```

```text
<Audio 2>：reference - 目标说话人遵循 <Audio 2> 的音色和沉稳表达方式，不复制原始信号。
```

每个关系标记仅在该标签在 `subject_definitions` 中已定义的角色范围内选择。不要将目标视频中新添加的动作、背景或情节事件视为参考保真度的损失。

## 5. detailed_description（详细描述）

这是全参考改写的核心主体。按目标视频播放顺序逐镜头描述视觉、动作、声音和对话，并在适用位置插入参考标签。

### 5.1 基本格式

遵循视频提示词写作指南（T2VA / I2VA / FL2VA / L2VA）的基本格式：

- 主体用英文。保留对话、歌词和可视文字的原始语言。
- `[Shot 1]` 标记开场镜头，不写时间戳。后续镜头用 `[Shot N] 在 MM:SS.mmm 处，...` 标记切换时间。
- 摄像机运动写成当前镜头内的自然英文，含运动类型、幅度和速度（当需要表达时）。
- 有声源使用稳定的 `(S1)`、`(S2)` 等 ID。对话和歌词写为 `<d>[语言] ...</d>`。
- 跨镜头对话使用 `<scenetrans>`、`<cutoff>` 及对应的连续性描述——跨越切换的对话、因视频结束截断的语音、跨镜头的连续音频。

完整的摄像机词汇、群体说话、画外音、跨镜头对话和可视文字规则，请参见视频提示词写作指南（T2VA / I2VA / FL2VA / L2VA）。

### 5.2 全参考模式的差异

| 维度 | T2VA | 全参考模式 |
| --- | --- | --- |
| 主字段 | `integrated_multimodal_description` | `detailed_description` |
| 风格开头 | 写在 `[Shot 1]` 之后 | 在 `[Shot 1]` 之前用 1-2 个英文句子确立 |
| 参考信息 | 不使用全参考标签 | 在首次出现及角色适用处插入 `<Subject N>`、`<Picture N>`、`<Video N>`、`<Audio N>` |
| 音频关系 | 描述目标视频自身的声音 | 在对应镜头或音频阶段引用 `<Audio N>`，说明信号是复制还是参考 |

开头示例：

```text
目标视频采用电影化、文学音乐视频风格，柔和的灯光和略微降低饱和度的色彩调色板。
[Shot 1] 场景在一条拥挤的城市街道展开……
[Shot 2] 在 00:09.000 处，镜头切换至极特写……
```

对于生成任务，`detailed_description` 通常为 350-500 个英文词。对话密集的内容优先适配完整口语时间线，而非机械达到字数。视频编辑描述随源视频复杂度缩放，无需遵循生成任务的范围。单镜头不应自动缩短描述；应按信息密度在各个镜头间分配细节。

### 5.3 在镜头中使用参考标签

在重要的 `<Subject N>` 首次清晰出现时，在镜头实际可见内容中描述其参考特征、在画面中的位置和当前动作。后续镜头继续使用相同标签，不再重新定义。

具体帧锚点使用自然表述：

```text
镜头从 <Picture 1> 开始
镜头的关键帧对应 <Picture 2>
镜头结束于 <Picture 3>
```

编辑或延续原始视频时，在源状态、结构或延续关系适用处自然地引用 `<Video N>`。在音频关系活跃的镜头或语义阶段引用 `<Audio N>`。

### 5.4 说话人、音频源与对话

基本的说话人 ID 和 `<d>` 格式遵循 T2VA。当参考的主体实际说话时，同时保留视觉参考标签和说话人 ID：

```text
<Subject 2> (S1) 转而对那位女性说道，<d>[English] Last summer, I went to my grandfather's house. He talked about you.</d>
```

`<Subject N>` 标识参考主体，`(Sx)` 标识实际说话人。主体说话时写 `<Subject N> (Sx)`。如果同一主体在画外说话，保持相同形式并标注 `画外（off-screen）`。当说话人不对应已定义主体时，使用稳定的声音描述后跟 `(Sx)`。

当语言内容仅是直接复用的 BGM 或完整配乐中的提示片段，且无人物、角色、叙述者或其他独立有声源实际产生时，用 `<Audio N>` 作为可闻来源，不要凭空创建额外的 `(Sx)`。如果有具体人物、角色、叙述者或其他独立有声源产生声音，则为该声源分配并复用 `(Sx)`：

```text
当 <Audio 1> 到达歌词 <d>[English] I'm lonely lonely lonely lonely lonely I'm lonely</d> 时，<Subject 1> 做出对应的手势，不成为独立的说话人来源。
```

当参考音频中的对话、叙述或歌词被直接复用，或输入提示词明确要求重新演绎时，在 `<d>` 内保留精确的原始词和原始语言。听不懂的片段写 `[unclear]`，不要猜测或释义。将标点标准化为表达句子所需的基本书面符号（`, . ? !`），去除重复的波浪线、表情符号、项目符号和重复/装饰性标点。完整的陈述、疑问和感叹句在 `</d>` 前分别以 `.`、`?` 或 `!` 结尾。

仅参考音色、节奏、情感或表达方式时，不要将参考音频中的原始对话带入目标视频。

按目标视频中实际发声事件的顺序一次性分配 `(Sx)`。在 `detailed_description` 中每次实际发声事件都复用对应 ID；在 `subject_definitions` 中绑定目标说话人的 `<Audio N>` 定义也复用同一 `(Sx)`，但不独立分配新 ID。不要在 `retention_analysis` 中写 `(Sx)`。

## 6. overall_soundscape 与 non_diegetic_music

这两个声音类别的定义遵循视频提示词写作指南（T2VA / I2VA / FL2VA / L2VA）。

`overall_soundscape` 总结全视频的环境和物理声音。对话、歌唱和与特定镜头同步的声音事件保留在 `detailed_description` 中：

```text
overall_soundscape: 安静的室内房间底噪和低沉的通风嗡鸣贯穿整个视频。
```

`non_diegetic_music` 描述角色听不到、只有观众能听到的背景音乐。有音乐时，说明其乐器、速度（节奏）和动态发展：

```text
non_diegetic_music: 一首克制的钢琴独奏配乐，慢速，底下是持续的低音大提琴，无渐强变化。
```

当使用参考音频时，仅在匹配可闻层次的对应部分中说明其复制或参考关系：环境音效归入 `overall_soundscape`，观众专属配乐归入 `non_diegetic_music`。如果同一音频同时提供两类内容，在各部分分别描述对应关系：

```text
overall_soundscape: 来自 <Audio 1> 的已复制环境层贯穿整个目标视频。
non_diegetic_music: <Audio 2> 被直接复用为完整的观众专属配乐。
```

完整的对话和歌词仅写在 `detailed_description` 的 `<d>` 中，不要在这两部分重复。

## 7. 完整示例

```text
subject_definitions:
<Subject 1> 是 <Picture 1> 中的咖啡店环境，包括裸露砖墙、橙色簇绒沙发及花纹靠垫、霓虹招牌和木质咖啡桌。
<Subject 2> 是 <Picture 2>、<Picture 3> 和 <Picture 4> 中的蓬松白色萨摩耶犬，具有厚实的白色毛发、尖耳朵、黑色鼻子和卷曲尾巴。
<Subject 3> 是 <Video 1> 中的年轻金发女性，拥有金色长发和一件卷起袖子的淡粉色扣领衬衫。
<Subject 4> 是 <Video 2> 中的年轻男性，拥有棕色短发和一件带抽绳的深灰色连帽衫。
<Audio 1> 是 <Subject 3> (S1) 的音色参考，包含一条英语口语声道。

summary:
[reference generation + audio reference] 目标视频展示 <Subject 3> 在 <Subject 1> 中吃饼干。<Subject 4> 带着 <Subject 2> 进入，狗狗扑向饼干。三镜头交替使用 <Audio 1> 作为 <Subject 3> 的音色参考，结尾是罐装观众笑声。

retention_analysis:
<Subject 1>（出现在 [Shot 1]、[Shot 2]、[Shot 3]）：fully_preserved - 保留裸露砖墙、橙色簇绒沙发、花纹靠垫、霓虹招牌和木质咖啡桌。
<Subject 2>（出现在 [Shot 1]、[Shot 2]）：fully_preserved - 保留萨摩耶的厚实白毛、尖耳朵、黑鼻子和卷曲尾巴。
```
