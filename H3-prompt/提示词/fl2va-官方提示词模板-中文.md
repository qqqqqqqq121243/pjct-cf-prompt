# 视频提示词写作指南（T2VA / I2VA / FL2VA / L2VA）中文版

## 1. 任务概述

- **T2VA**：从文本构建完整的视听时间线。
- **I2VA**：T2VA 主体 + 首帧指令 + 从首帧向前发展的视觉路径。
- **FL2VA**：T2VA 主体 + 首尾帧指令 + 从首帧到尾帧的连续路径。
- **L2VA**：T2VA 主体 + 尾帧指令 + 从合理的先前状态汇聚到尾帧的路径。

## 2. 最终提示词结构

### 2.1 第一部分：指令

**T2VA** 没有图像对齐指令，直接从三个核心字段开始。

**I2VA** 始终使用：

```text
对于目标视频，在目标视频的 0.00 秒处，<Picture 1>（来自 [Shot 1]）被完全参考。
```

**FL2VA** 始终使用：

```text
参考图片与目标视频的对齐方式 — Picture 1（来自 Shot 1）对齐目标视频的 0.00 秒标记处；Picture 2（来自 Shot N）对齐目标视频的 S.SS 秒标记处。
```

**L2VA** 始终使用：

```text
参考图片与目标视频的对齐方式 — <Picture 1>（来自 [Shot N]）对齐目标视频的 S.SS 秒标记处。
```

其中 `N` 是实际最终镜头的索引，`S.SS` 是有效视频时长，精确到两位小数。指令必须是最终提示词的第一行，之后空一行再跟核心字段。

### 2.2 第二部分：三个核心字段

```text
integrated_multimodal_description: [Shot 1] ...

overall_soundscape: ...

non_diegetic_music: ...
```

- **integrated_multimodal_description**：沿时间线描述视觉、动作、镜头、说话人、对话、歌唱和剧情内音频。
- **overall_soundscape**：总结整个视频中的环境声音、物理动作声音和非语言人声。
- **non_diegetic_music**：描述角色听不到、只有观众能听到的背景音乐。

## 3. 如何在多模态描述中融入关键帧

### 3.1 I2VA：从图像开始向前发展

`<Picture 1>` 是视频在 0.00 秒处的实际首帧，属于 `[Shot 1]`。描述应首先确定图像中的风格、主体、构图和场景锚点，然后描述接下来的动作。角色身份、服装、颜色、关键物品和空间关系应保持一致。

推荐结构：**首帧锚定 → 动作开始 → 持续发展 → 结果或反应**。

### 3.2 FL2VA：描述首帧和尾帧之间的路径

Picture 1 是开头，Picture 2 是结尾。重点描述主体如何移动、姿势如何变化、物体如何被操控、构图如何演变，以及场景或光线如何过渡。

FL2VA 通常倾向于单镜头，以便模型能够从首帧到尾帧连续插值。仅当明确指定时才使用多镜头。尾帧必须在视频结尾的最终 `[Shot N]` 中到达。

推荐结构：**首帧状态 → 可观察的中间变化 → 逐步缩小的差异 → 尾帧状态**。

### 3.3 L2VA：推断开头并在结尾着陆到图像

`<Picture 1>` 是视频的最终帧，属于最后一个 `[Shot N]`；它本身不属于 Shot 1。根据用户意图和尾帧推断合理的先前状态，然后描述角色、物体、摄像机和场景如何逐步接近参考图像。

推荐结构：**合理的先前状态 → 明确动作与过渡路径 → 最终镜头中逐步汇聚 → 尾帧着陆**。

## 4. 如何编写三个共享核心部分

### 4.1 沿时间线展开多模态描述

`integrated_multimodal_description` 是改写提示词的主体。每个细节应对应可见或可听的内容：视觉风格、初始构图、主体外观和位置、场景与关键道具、动作与反应、镜头切换、口头语言以及同步的剧情内声音。

在 `[Shot 1]` 的开头，陈述整体风格和初始构图。常见风格包括 `真人电影（Cinematic）`、`实拍（live-action）`、`2D 动画（2D-animated）`、`3D CG`、`黏土动画（claymation）`、`水彩（watercolor）` 和 `复古胶片（vintage film）`。对于关键帧任务，从参考图像中推测风格；对于 T2VA，从用户的文本中选择。

```text
[Shot 1] 真人电影风格，一个中景镜头框定……
```

### 4.2 镜头与切换

不要给第一个镜头添加时间戳。后续镜头使用顺序编号，每个镜头以严格递增的切换时间开头，且必须在视频时长范围内：

```text
[Shot 2] 在 00:03.500 处，镜头切换到……
```

普通切换使用"镜头切换到"、"画面切换到"、"镜头过渡到"、"镜头变为"或"镜头转至"。当用户明确要求时，也可使用交叉溶解、淡入淡出或划像。切换应引入关于主体、空间、状态、视角或时间的新信息。如果只需改变距离或微调角度，优先使用摄像机运动。

### 4.3 摄像机运动：运动类型 + 幅度 + 速度

完整的摄像机运动表达有三个维度：**运动类型**定义摄像机如何移动，**幅度**定义构图变化的范围，**速度**定义变化的速度。仅在有意义时添加幅度和速度；中等幅度和正常速度通常省略。

| 维度 | 可用表达 | 说明 |
|-|-|-|
| 运动类型 | `推近 / 拉远（Zoom In / Zoom Out）` | 机身不动，焦距变化 |
| 运动类型 | `推进 / 拉出（Push In / Pull Out）` | 摄像机向前 / 向后移动 |
| 运动类型 | `左摇 / 右摇（Pan Left / Pan Right）` | 摄像机原地不动，镜头水平旋转 |
| 运动类型 | `左移 / 右移（Truck Left / Truck Right）` | 摄像机水平平移 |
| 运动类型 | `上摇 / 下摇（Tilt Up / Tilt Down）` | 摄像机原地不动，镜头垂直旋转 |
| 运动类型 | `上升 / 下降（Pedestal Up / Pedestal Down）` | 整个摄像机向上 / 向下移动 |
| 运动类型 | `弧形运动（Arc Shot）` | 摄像机围绕主体做弧线运动 |
| 运动类型 | `跟拍（Tracking Shot）` | 摄像机跟随移动中的主体 |
| 运动类型 | `静止镜头（Static Shot）` | 摄像机位置和镜头均保持不动 |
| 运动类型 | `轻微抖动 / 强烈抖动（Shake Slightly / Shake Strongly）` | 轻微 / 强烈的摄像机抖动 |
| 运动类型 | `主观视角（POV）` | 主体的第一人称视角 |
| 运动类型 | `顺时针旋转 / 逆时针旋转（Roll Clockwise / Roll Counterclockwise）` | 摄像机围绕镜头轴旋转 |
| 幅度 | `小幅（with small amplitude）` | 小范围变化 |
| 幅度 | `大幅（with large amplitude）` | 大范围变化 |
| 速度 | `慢速（at slow speed）` | 缓慢移动 |
| 速度 | `快速（at fast speed）` | 快速移动 |

摄像机运动应写成镜头内自然的英文动作描述，而不是堆在句子末尾的单独标签：

```text
摄像机以小幅慢速向她手中折叠的信纸推进。
摄像机以大幅快速向右摇摄，展现敞开的门口。
摄像机保持静止镜头，跑步者跑出画面。
```

### 4.4 说话人、对话与歌唱

说话、唱歌或发出画外人声的主体使用稳定 ID，如 `(S1)` 和 `(S2)`。当多个已编号的说话人同时说话或合唱时，使用复合 ID，如 `(S1,S2)`。同一说话人在不同镜头中保持相同 ID；从未发声的角色不分配说话人 ID。

当说话人首次出现时，从视觉和音频上下文中提供足够的信息以建立稳定身份，例如角色类型、年龄、性别、是否在画面内、音高、音色、语速或口音。将说话人的识别短语、ID、动作和表达方式放在 `<d>` 标签**外部**。在 `<d>` 标签**内部**，仅包含语言标签和用户提供的实际口语内容。逐字保留原文的每个单词和标点；不要翻译或改写。

```text
那位声音轻柔、带气息声的年轻女性（S1）说道：<d>[English] I get off at the next station.</d>
那两个孩子（S1,S2）一起喊道：<d>[English] Wait for us!</d>
```

对于画外音，使用精确短语 `以画外音的方式说道（says in an off-screen voiceover）`。在每个画外音 `<d>` 块之后立即说明对应画面内角色的嘴唇保持闭合：

```text
那位男子（S1）以画外音的方式说道：<d>[English] I still remember that road.</d> 同时他的嘴唇完全闭合。
```

当同一句台词或歌词跨越镜头切换时，在两个部分中使用 `<scenetrans>` 标记连接点，并明确说明音频在切换中持续。使用 `<cutoff>` 标记因视频结束而截断的语音。连续性可以表达为"无缝地跨越切换持续"、"不间断地延续到下一个镜头"、"从前一个镜头延续而来"或"在过渡过程中仍然可闻"。

### 4.5 屏幕文字

将屏幕上实际可见的任何横幅、标志、标签、字幕或霓虹灯文字放入英文双引号中。逐字保留原文和标点，不进行翻译。

```text
门上方亮着一块红色霓虹招牌，写着 "营业中"。
```

### 4.6 overall_soundscape（整体声音场景）

用 1-4 个英文句子组成一个连续段落，总结整个视频中的环境声音、物理动作声音和非语言人声，如风声、雨声、交通声、脚步声、衣物摩擦声、撞击声、呼吸声、笑声或喘息声。对话、歌唱和剧情内音乐已属于多模态描述，不应在此重复。仅当用户明确要求整个视频完全安静时使用 `N/A`。

```text
overall_soundscape: 持续的雨水敲打着咖啡馆的窗户，底下是低沉的室内环境音。门铃响了一次，随后是湿漉漉的脚步声和椅子轻柔的刮擦声。
```

### 4.7 non_diegetic_music（非剧情音乐）

用 1-3 个英文句子描述角色听不到、只有观众能听到的背景音乐。重点描述乐器、速度、节奏和动态变化；不要使用抽象的情绪词汇或解释配乐的情感功能。角色可听到的歌唱、乐器、收音机、电视或手机音乐是剧情内事件，应出现在多模态描述中。没有非剧情音乐时使用 `N/A`。

```text
non_diegetic_music: 稀疏的钢琴音符，慢速，辅以持续的低音弦乐，音量逐渐增大后淡出。
```

## 5. 案例

### 案例 1：T2VA（文本到视频）

没有参考图像，直接从文本构建完整的时间线。可以添加与用户意图保持一致但更丰富的场景、角色、动作和声音细节。

```text
integrated_multimodal_description: [Shot 1] 真人电影风格，一个中景镜头框定日出前一位面包师打开街边小面包店的百叶窗。摄像机以小幅慢速向前推进，那位声音沉稳、略带沙哑的中年面包师（S1）将一条新鲜面包放在木质柜台上，说道：<d>[English] First batch of the morning.</d> [Shot 2] 在 00:05.000 处，镜头切换到热气从切片面包上升起的特写，同时面包师刚才的话音从前一个镜头延续而来。

overall_soundscape: 木质百叶窗在安静的街道上刮擦着打开，面包店内有托盘轻柔的碰撞声。门铃响了一次，随后是轻轻的脚步声和面包被切开的清脆声响。

non_diegetic_music: 柔和的木吉他弹奏，中等速度，辅以稀疏的低音提琴音符，结尾时轻轻淡出。
```

### 案例 2：I2VA（图像到视频）

先写首帧指令，然后用 Picture 1 中的主体、构图和场景作为 Shot 1 的起点，再描述场景如何继续发展。

```text
对于目标视频，在目标视频的 0.00 秒处，<Picture 1>（来自 [Shot 1]）被完全参考。

integrated_multimodal_description: [Shot 1] 真人电影风格，<Picture 1> 中展示的年轻女性停留在雨淋湿的火车窗边，保持其外观、服装、座位位置和车厢布局不变。摄像机以小幅慢速向右平移，她从折叠的信纸上抬起目光，望向窗外流动的城市灯光。她的倒影在玻璃上移动，同时那位安静、气息轻柔的年轻女性（S1）说道：<d>[English] I get off at the next station.</d> 她沿着原有的折痕将信纸折好。

overall_soundscape: 火车轮轨发出稳定的金属节奏，底下是低沉的通风嗡鸣声。雨水敲击着窗户，纸在她手中轻柔沙沙作响。

non_diegetic_music: 持续的大提琴长音，节奏缓慢，伴以间隔较宽的钢琴音符，音量逐渐减弱。
```

### 案例 3：FL2VA（首尾帧到视频）

两张图片分别锚定开头和结尾。主体部分不应重复两张静态图片的描述，而应提供连接它们的运动路径。以下示例为 8 秒单镜头。

```text
参考图片与目标视频的对齐方式 — Picture 1（来自 Shot 1）对齐目标视频的 0.00 秒标记处；Picture 2（来自 Shot 1）对齐目标视频的 8.00 秒标记处。

integrated_multimodal_description: [Shot 1] 真人电影风格，一位被雨水淋湿的骑行者以 Picture 1 确立的位置和构图开始，在银色自行车旁握着一把合拢的黑色雨伞。摄像机以小幅慢速向后拉远，同时她松开自行车把手，将伞举过肩膀，向上按压伞骨滑套直到伞面撑开。水珠从展开的伞面上滚落，她走到伞下，旋转伞柄至最终角度，在镜头末尾定格为 Picture 2 所确立的姿势、间距和构图。

overall_soundscape: 雨水持续落在人行道上，随后是伞骨滑套的金属咔嗒声和伞面打开的轻柔嘭声。水滴从自行车架上滴落，远处有车流经过。

non_diegetic_music: N/A
```

### 案例 4：L2VA（尾帧到视频）

图片仅锚定最终时刻。首先建立一个兼容的先前状态，然后让动作、物体状态和构图在最终镜头中逐步着陆到 Picture 1。以下示例为 6 秒单镜头。

```text
参考图片与目标视频的对齐方式 — <Picture 1>（来自 [Shot 1]）对齐目标视频的 6.00 秒标记处。

integrated_multimodal_description: [Shot 1] 真人电影风格，一个特写镜头开始于一只完好的水杯靠近深色木桌边缘，<Picture 1> 中可见的同一只手和袖子从右侧靠近。摄像机以小幅慢速向前推进，指尖撞击杯沿。玻璃杯倾斜、倒下，并重重地砸在地面上；裂缝蔓延开来，碎片向外滑动。接近结尾时，移动的碎片失去动量，最终定格为 <Picture 1> 所确立的破碎排列、手部位置、摄像机角度、光线和最终构图。

overall_soundscape: 指尖轻敲玻璃杯，随后杯子在桌面上刮擦、倒下，发出尖锐的破裂声。细小碎片四散开来，逐渐在地板上停止滑动。

non_diegetic_music: 缓慢的低频电子脉冲，在玻璃破碎后立即结束。
```
